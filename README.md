# Anand Raut — Personal Portfolio

A responsive student portfolio made with HTML and CSS. It introduces Anand, shares his beginner skills and projects, and includes a contact form.

## View the website

Open `index.html` in a web browser. The illustrations are stored in `assets/`, and all page styling is in the external `style.css` file.

## Contact form

The form checks that all fields are filled in and that the email address is valid. Submitting it opens the visitor's default email app to send a message to `anandcet07@gmail.com`; it does not use a server.

## Screenshots

Desktop and mobile screenshots are in `screenshots/`. The LinkedIn link currently opens LinkedIn; replace it with a personal profile link if you have one.
